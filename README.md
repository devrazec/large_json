# large_json
Project to explore a way to handle largo json files with Next.js

# Create Nextjs Project

```
-- Create Nextjs Project

curl https://codeload.github.com/mui/material-ui/tar.gz/master | tar -xz --strip=2  material-ui-master/examples/material-ui-nextjs
cd material-ui-nextjs

move to .

-- Install

npm i

-- Components

npm i -S dexie dexie-react-hooks


-- Create Global React Context

-- Commands

npm run dev
npm run build

-- Start Local Server

npx serve@latest out

```
